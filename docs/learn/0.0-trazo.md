# Trazo concepts for batch 0.0

1. **P10 / P50 / P90:** three percentiles of the predicted 12-month oil. A
   wider range means more uncertainty. Like a delivery ETA of "2 to 5 days".
2. **sigla vs idpozo:** `sigla` = the physical well; `idpozo` = a record id.
   Like Order vs OrderLine. Group by `sigla` before splitting train and test.
3. **One writer per schema:** each service has its own database role. The
   database refuses writes outside its schema (`permission denied`).
4. **Idempotent load:** run twice, same result (upsert).
5. **Abstention:** when there is no evidence, say what was searched and that
   nothing was found. Never invent. Like a 404.
6. **Request path:** browser to API only. The API forwards chat to the
   assistant; the assistant reads data through a read-only role.
